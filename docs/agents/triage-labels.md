# Triage labels

Map canonical triage roles to these tracker strings:

| Role | Tracker string | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on the reporter for information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

For local Markdown tickets, record the tracker string in `Status:`.
Edit the tracker string column to change the vocabulary.
