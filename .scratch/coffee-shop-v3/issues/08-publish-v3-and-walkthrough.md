**What to build:** el visitante abre la V3 publicada, prueba la demo conectada y encuentra un README y un video corto que muestran la compra y la administración reales de demostración.

**Blocked by:** 07 — Completar el recorrido conectado en idiomas y tamaños.

**Status:** ready-for-agent

- [ ] Publicar frontend en Vercel, API NestJS en Render Free y PostgreSQL en Neon Free usando configuración gratuita y sin secretos versionados.
- [ ] Ejecutar migraciones y carga inicial explícitas; reinicio de servicio no destruye pedidos y disponibilidad lenta de servicios gratuitos tiene respuesta comprensible.

- [ ] README explica V3, acceso demo, datos compartidos/reset, compras simuladas, arquitectura y ejecución local.
- [ ] Grabar 60–75 segundos reales, silenciosos a 1080p, principalmente móvil, con textos ingleses y final breve de escritorio; mostrar compra conectada y administración.
